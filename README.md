## 📖 项目简介

LLM Hub 是一个网页端的大模型聊天网站集成应用。它利用左侧边栏集中管理多个 LLM（大型语言模型）对话网站，为您提供一站式的 AI 交互体验。用户可以自由添加、删除自己心仪的 LLM 网站，并对这些网站的顺序进行调整。

## ✨ 功能特性

* **一站式管理**：通过左侧边栏轻松管理和切换多个主流大模型网站。
* **智能加载机制**：
  * ✅ **支持 iframe 的网站**：直接在右侧核心区域无缝加载，无需频繁切换标签页。
  * 🪟 **不支持 iframe 的网站**：自动在新标签页或新窗口中安全打开聊天软件。
* **自定义配置**：支持自由添加、删除模型节点并调整排序。
* **本地安全存储**：登录网站的用户名、密码及应用的个人配置均在本地安全存储。

## 🧩 进阶配置：解决 iframe 限制

部分网站会有跨域或嵌套限制。安装以下浏览器插件后，可尝试在 iframe 中强制加载更多网站：

| **插件名称**      | **下载渠道**         | **作用说明**                                            |
| ------------- | ---------------- | --------------------------------------------------- |
| **Allow CSP** | Chrome Web Store | 解除网站的 Content Security Policy (CSP) 限制，允许 iframe 嵌入 |

---

## 🛠️ 如何添加新模型？

1. 点击页面右上角的 **「添加模型」**。

2. 在弹出的表单中输入该模型的 **名称**、**URL** 和 **图标**。

3. 点击 **「添加」** 完成配置。

4. **注意**：如果明确知道该 LLM 网站不支持 iframe 嵌套，请务必勾选 **新窗口打开**。
